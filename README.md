# Customer Insight AI

An AI-powered customer feedback analyzer built with Python, Streamlit, Pandas, and Ollama.

## What it does

This application allows a business to upload a customer feedback CSV file and automatically analyzes the feedback using AI.

It provides:

- Customer sentiment
- Main customer issue
- Recommended business action
- Sentiment dashboard
- Customer issue analysis
- Search and filtering
- Overall business insight
- Downloadable analysis report

## How it works

Customer CSV
→ Python/Pandas
→ Ollama AI
→ Customer Analysis
→ Dashboard
→ Business Insights
→ Download Report

## Technologies

- Python
- Pandas
- Streamlit
- Ollama
- Phi-3

## CSV Format

The uploaded CSV must contain:

Customer,Feedback

Example:

Customer,Feedback
Ali,"The phone battery does not last long."
Sara,"I really love the camera and performance."

## How to run

Install the required packages:

pip install -r requirements.txt

Then run:

streamlit run app.py

## Business Use Case

Businesses can use this application to quickly analyze large amounts of customer feedback and identify common problems and customer satisfaction.
